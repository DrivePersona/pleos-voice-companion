# 보이스 컴패니언 디자인 시스템 v0.1

## 목적과 적용 범위

이 문서는 차량용 보이스 컴패니언의 Compose 화면을 위한 제품 디자인 계약이다.
색상과 인터랙션은 Pleos 차량 환경의 안전·가독성 원칙을 우선하며, 특정 금융 앱 또는 모바일 앱의 디자인 시스템을 색상 기준으로 사용하지 않는다.

시각 요소보다 차량 안전 규칙이 우선한다. Pleos의 주행 안전 원칙에 따라 주행 중에는 시각·인지 부담을 줄이고, 정차 중에만 개인화 기능을 제공한다.

## 제품 경험

| 상태 | 역할 | UI 원칙 |
| --- | --- | --- |
| 정차 | 내 차의 목소리와 캐릭터를 고르는 개인화 공간 | 팩 선택·대사 편집·미리듣기·VR 설정을 제공한다. |
| 주행 | 짧고 신뢰할 수 있는 음성 동반자 | 설정·캐릭터·CTA를 제거하고 음성 반응과 핵심 상태만 보여 준다. |

`CarUxRestrictions`가 항상 실제 주행 제약의 기준이다. 기어·속도를 자체 추측해 UI 정책을 바꾸지 않는다.

## 토큰

토큰은 `app/src/main/java/com/example/voicecompanion/ui/theme/CompanionTheme.kt`가 유일한 정의 위치다. 화면에서 색상이나 간격 수치를 직접 만들지 않는다.

- **기본 표면:** 주간은 `#F3F5F7` 캔버스·`#FFFFFF` 표면·`#18212B` 텍스트, 야간은 `#0E1218` 캔버스·`#171D25` 표면·`#F2F5F7` 텍스트를 사용한다.
- **개인화 포인트:** 저채도 바이올렛 `#5B4DB3`(야간 `#C9C2FF`)은 정차 중 팩 선택, VR 시작, 캐릭터 관련 상태에만 사용한다.
- **차량 의미 색상:** 위험·주의·규제·공조·운전자 보조 색상은 앱이 정의하거나 일반 CTA에 재사용하지 않는다. Pleos/OEM 시스템 토큰과 정책을 따른다.
- **라이트/다크:** 시스템 모드에 맞춰 각각의 `ColorScheme`을 제공한다. 한 모드의 값을 다른 모드에 그대로 재사용하지 않는다. 향후 차량의 주·야간 모드 API가 확정되면 시스템 다크 모드 대신 그 신호를 우선한다.
- **타이포그래피:** 시스템 산세리프를 사용한다. 제목은 `headlineSmall`/`titleMedium`, 본문은 `bodyLarge`/`bodyMedium`, 상태 라벨은 `labelMedium`을 쓴다.
- **간격과 모서리:** 페이지 20dp(좁은 화면 16dp), 섹션 20dp, 카드 20dp, 행 16dp, 버튼 14dp를 기본값으로 둔다.
- **터치 영역:** 조작 가능한 행·버튼의 최소 높이는 52dp다.

## 공통 컴포넌트

`ui/component/CompanionComponents.kt` 외부에서 개별 `Surface`, 기본 버튼의 시각 규칙을 새로 만들지 않는다.

| 컴포넌트 | 용도 |
| --- | --- |
| `CompanionCard` | 한 목적을 가진 정보·설정 블록 |
| `CompanionSectionHeader` | 짧은 제목과 한 줄 보조 설명 |
| `CompanionBadge` | 정차/주행 같은 짧은 상태 표현 |
| `CompanionListRow` | 팩처럼 하나를 고르는 선택 행 |
| `CompanionPrimaryButton` | 한 화면 또는 섹션의 핵심 행동 |
| `CompanionSecondaryButton` | 보조·되돌릴 수 있는 행동 |

## 콘텐츠와 상태 규칙

- 한 메시지는 가능하면 1~2줄, 최대 3줄로 끝낸다. 상태는 `현재 상태 + 가능한 다음 행동`으로 쓴다.
- 선택 불가 항목은 흐리게만 만들지 않고 이유를 함께 보인다.
- 색상만으로 성공·주의·비활성을 전달하지 않는다. 텍스트 상태를 병기한다.
- 주행 중에는 자동 스크롤, 장식적 모션, 반복 애니메이션을 사용하지 않는다.
- 주행 화면에는 설정 행·팩 선택·주요 CTA를 표시하지 않는다. 개발용 시뮬레이터는 debug 빌드에만 둔다.
- 캐릭터의 시각 반응은 정차 중 VR 오버레이에 한정한다. GLB 3D와 2D 스프라이트 모두 이 제약을 따르며, 안전 경고에는 캐릭터 연출을 붙이지 않는다.
- 모든 터치 조작은 한 손으로 가능한 짧은 행동이어야 한다. 긴 대사 입력·팝업 다단계 흐름은 정차 상태에서만 제공한다.

## 구현 경계

Compose Material 3는 렌더링 기반이다. 화면은 `CompanionTheme`과 `Companion*` 컴포넌트만 사용하며, 비즈니스 로직은 `ViewModel`과 `CompanionTouch`를 통해서만 호출한다. 새 화면을 만들 때는 먼저 이 문서에 필요한 토큰 또는 공통 컴포넌트를 추가한 뒤 화면에 적용한다.
